How a round works

Each station deals 8 fresh problems (the Final Mix deals 10). A right answer on the first try earns 10 points. After a wrong answer, the game names the likely mistake and gives one more try for 5 points.

The "Show me" hint

Hints use the tools from class: more batches in a diagram, filled-in ticks on a double number line, a "1" row in a table, and a number written in every box of a tape diagram. A used hint caps that problem at 5 points.

Mistakes it catches

Writing a ratio in the wrong order, adding the same amount to both quantities instead of multiplying, comparing totals instead of the price for one, and treating one box of a tape diagram as the whole part.

Not covered

Lesson 17 (a Fermi estimation problem) is open-ended, so it works better as a class discussion than as a scored game.
