Part A · Lessons 1–2

Tape diagrams and equations

Learn chapter →

Know it

  • An equation says two amounts are equal. It can be true (9 + 6 = 5 + 10) or false.
  • A tape diagram shows one: three equal pieces x making 18 is 3x = 18; a piece x and a piece 3 making 18 is x + 3 = 18.
  • A solution is a value that makes the equation true.
  • Check by putting the value back in: 3 · 6 = 18 ✓.

Example

Write an equation for the tape, and solve it.

Three pieces of x make 18: 3x = 18, so x = 6. Check: 6 + 6 + 6 = 18 ✓.

Watch out: 18 · 3 = x mixes up the whole and its parts. The 18 is the whole tape, split into 3 parts.

Part B · Lessons 3–5

Staying in balance

Learn chapter →

Know it

  • A balanced hanger is like an equation: both sides weigh the same.
  • Do the same move to each side to keep it balanced.
  • Undo adding by subtracting: x + 5 = 9, so x = 9 − 5 = 4.
  • Undo multiplying by dividing: 5x = 8.5, so x = 8.5 ÷ 5 = 1.7.
  • a⁄b means a ÷ b: 8x = 3, so x = 3⁄8.

Example

Each circle weighs x, and each square weighs 1. The hanger is balanced. Find x.

4x = 12. Divide each side by 4: x = 3. Check: 4 · 3 = 12 ✓.

Watch out: 4x means 4 times x. Subtracting 4 from each side (to get 8) doesn’t undo it; divide.

Part C · Lessons 6–7

Letters stand for numbers

Learn chapter →

Know it

  • An expression can use a letter for a number: “7 less than t” is t − 7, “3 times n” is 3n.
  • The coefficient multiplies the letter: 2x means 2 · x.
  • To evaluate, put the number in for the letter: when x = 3, 10 + 2x = 10 + 6 = 16.
  • Percents work with letters too: 30% of x is 0.3x.

Example

A pack has p pencils. Write an expression for 3 packs and 2 loose pencils. How many pencils is that if p = 12?

3p + 2

When p = 12: 3 · 12 + 2 = 36 + 2 = 38 pencils.

Watch out: when x = 3, 2x is 6, not 23. And “7 less than t” is t − 7, not 7 − t.

Part D · Lesson 8

Equal and equivalent

Learn chapter →

Know it

  • Two expressions are equivalent when they are equal for every value of the letter.
  • One value that gives different answers shows they are not equivalent. One value that gives the same answer isn’t enough to show they are.
  • Combine like terms: x + x + x = 3x, and 8x − 3x = 5x.

Example

Are 2x and x + 2 equivalent? Try some values:

123
244
365

They’re equal only when x = 2, so they are not equivalent.

Watch out: matching at one value (like x = 2 above) doesn’t make two expressions equivalent. Try a few values.

Part E · Lessons 9–11

The distributive property

Learn chapter →

Know it

  • Split a rectangle into two: 8 · 26 = 8 · 20 + 8 · 6 = 160 + 48 = 208.
  • The same works with letters: a(b + c) = ab + ac.
  • With subtraction, multiply both terms too: 3(x − 4) = 3x − 12.
  • Backwards, take out the greatest common factor: 10x + 15 = 5(2x + 3).

Example

Write 4(x + 5) without parentheses.

The two parts are 4 · x and 4 · 5: 4(x + 5) = 4x + 20.

Check with x = 1: 4 · 6 = 24 and 4 + 20 = 24 ✓.

Watch out: the number outside multiplies every term inside. 3(x − 4) is not 3x − 4.

Part F · Lessons 12–13

Meaning of exponents

Learn chapter →

Know it

  • An exponent says how many times to multiply the base by itself: 43 = 4 · 4 · 4 = 64.
  • “Squared” is the exponent 2 (a square’s area, s2); “cubed” is 3 (a cube’s volume, s3).
  • Fractions work the same way: (2⁄3)2 = 2⁄3 · 2⁄3 = 4⁄9.
  • 1 to any power is 1, and 103 = 1,000.

Example

Compare 25 and 52.

25 = 2 · 2 · 2 · 2 · 2 = 32

52 = 5 · 5 = 25

Switching the base and the exponent changes the value: 25 is greater.

Watch out: 43 is 4 · 4 · 4 = 64, not 4 · 3 = 12.

Part G · Lessons 14–15

Evaluating expressions with exponents

Learn chapter →

Know it

  • The order: parentheses first, then exponents, then multiply and divide, then add and subtract.
  • The exponent belongs only to what it touches: in 6x2 only x is squared. When x = 3, 6x2 = 6 · 9 = 54.
  • To solve 3x = 81, multiply 3s until you reach 81: 3 · 3 · 3 · 3 = 81, so x = 4.

Example

Evaluate 2 + 3 · 42.

Exponent: 42 = 16.

Multiply: 3 · 16 = 48.

Add: 2 + 48 = 50.

Watch out: 6x2 isn’t (6x)2. When x = 3, 6x2 = 54 but (6x)2 = 182 = 324.

Part H · Lessons 16–18

Two related quantities

Learn chapter →

Know it

  • When one amount depends on another, the independent variable is the one you choose, and the dependent variable depends on it.
  • A table, an equation, and a graph can show the same relationship: y = 5x or a = j + 3.
  • A point (2, 18) means the first variable is 2 and the second is 18. Order matters.

Example

Noah bikes 9 miles each hour: d = 9t, with t in hours and d in miles.

The point (2, 18): in 2 hours, Noah rides 18 miles. Check: 9 · 2 = 18 ✓.

Watch out: (2, 18) isn’t 18 hours and 2 miles. The independent variable (t) comes first.

Part I · Lesson 19

Tables, equations, and graphs

Learn chapter →

Know it

  • One situation can be shown four ways: in words, in a table, with an equation, and on a graph.
  • To answer a question, write an equation, solve it, and check the answer in the story.
  • If y goes up by the same amount each time x goes up by 1, starting at 0, the equation is y = (that amount) · x.

Example

Tickets to a school play cost $6 each. A class collected $138. How many tickets did it sell?

Let t be the tickets: 6t = 138.

Divide each side by 6: t = 23 tickets.

Check: 6 · 23 = 138 ✓.

Watch out: 138 − 6 takes away the price of only one ticket. 6t means 6 dollars for each ticket: divide.
