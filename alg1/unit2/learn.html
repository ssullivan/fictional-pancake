For grown-ups

How it works

Each chapter follows one IM lesson. Each step shows one idea with something to change, then a quick check. Some quick checks ask for an equation, typed in a box with math keys; the line under the box shows how it reads. Any equal way of writing it counts (5p + 40 = c is the same as c = 5p + 40). A wrong answer names the likely mistake and gives one more try. Progress is saved on this device.

Models and constraints

Lesson 1 sets up the unit’s words: a model uses letters for quantities and equations for how they’re related, and a constraint limits what’s possible, like whole pizzas or a budget.

Writing equations

Lessons 2 and 3 write equations from situations: a cost for each person plus a cost paid once, a price plus a percent of it, and patterns found in tables (a sum, a difference, or a product that stays the same). Trying a few numbers before using letters is the main strategy.

Solutions and graphs

Lessons 4 and 5: a solution makes an equation true. An equation in two variables has pairs of values as solutions, often many, and its graph shows all of them. Points on the line meet the constraint; points off it don’t.

Equivalent equations

Lesson 6: equations are equivalent when they have the same solutions. Adding or subtracting the same number on both sides, multiplying or dividing both sides by the same number (not 0), the distributive property, and combining like terms all keep the solutions, so solving an equation is a chain of equivalent equations. Doing something different to each side changes the solution.
